# journal/

One file per working session, named by date in ISO format
(`YYYY-MM-DD.md`), so the sequence of real progress is visible from the
file list alone without opening each entry.

This is the evidence base for the "no step was skipped or reordered" claim
made throughout this project's documentation — commit timestamps on these
files, cross-referenced against the repository's structural commits, are
what let a reader (or Dr. Shaalan, per UC-3 in the Design Review Package)
verify that work happened in the order this project claims it did, rather
than taking that claim on prose alone.
