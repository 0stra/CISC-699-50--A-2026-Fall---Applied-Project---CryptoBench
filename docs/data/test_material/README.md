# data/test_material/

This folder will hold the selected Java code samples and the list of
authorised TLS endpoints used in the pilot (FR-1).

Selection criteria, carried from the Literature and Requirements Brief and
the Design Review Package:

- Each Java code sample must be existing, publicly available material,
  selected rather than authored for this project, under a permissive
  licence recorded per sample.
- The set as a whole must include at least one deliberate known-negative
  case — material with no cryptographic asset — so false positives are
  measurable rather than merely absent (FR-5).
- TLS endpoints must already have legitimate, already-held testing
  authorisation before they are added here, confirmed and recorded in
  writing (NFR-7; see RISK-05 in the risk log).

This folder is empty as of this check-in. No material has been selected
yet — see the sprint reflection for why, and the next-sprint plan for when
selection happens.
